# Pixelmon Radar

Client-focused NeoForge sidemod for **Minecraft 1.21.1**, **NeoForge 21.1.248**, **Pixelmon 9.4.1**, and **Java 21**.

## Features
- Live nearby Pokemon radar and compact HUD
- Name, level, distance, XYZ, gender, form and palette information
- Shiny, legendary, mythical, Ultra Beast, Paradox and boss detection
- Search and distance/level/name/rarity sorting
- Shiny-only and rare-only filters
- Select a Pokemon to track with direction, distance and coordinates
- Rare Pokemon chat + sound alerts
- Rebindable Minecraft key mappings
- Configurable Pokemon detection radius
- Registry-driven ore/block selector including Pixelmon and other modded ores
- Searchable ore menu with persistent selections
- Configurable ore scan range
- Through-wall ore outline rendering
- Settings saved to config/pixelmonradar.json

## Default controls
- **R** - Open Pokemon Radar
- **H** - Toggle Pokemon HUD
- **O** - Open Ore Scanner
- **Unbound by default** - Toggle Ore Highlights

All controls can be rebound under Minecraft's normal Controls / Key Binds screen.

## Build
GitHub Actions builds the mod with Java 21. Download the newest successful Pixelmon-Radar artifact and use the JAR from build/libs.

This project is intended for local/single-player use.
