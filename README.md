# Pixelmon Radar

Client-focused NeoForge 1.21.1 sidemod for Pixelmon 9.4.1.

Planned modules:
- Pokemon radar/HUD, filters, rare/shiny alerts and tracking
- Rebindable Minecraft key mappings
- Registry-driven ore scanner including Pixelmon/modded ores
- Through-wall ore outlines with configurable range

Builds are produced by GitHub Actions using Java 21.
